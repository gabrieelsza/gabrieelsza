Desenvolvedor Front-End focado no desenvolvimento de interfaces responsivas, intuitivas e otimizadas para UX/UI. Cursando **Análise e Desenvolvimento de Sistemas na UCB** e atuando como **Técnico de Monitoramento na Lanlink (CNP Seguradora)**, acompanhando APIs em produção e gerenciando workflows ágeis com Jira.
